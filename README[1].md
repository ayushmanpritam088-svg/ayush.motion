# Ayushman Pritam — Video Editor Portfolio

A responsive one-page portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — scroll reveal animation

## Put it online with GitHub Pages
1. Create a new GitHub repository, for example `video-editor-portfolio`.
2. Upload all three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will give you the live `.github.io` address.

## Customize before publishing
- Replace the four placeholder project cards with your real work links/videos.
- Replace the WhatsApp link in `index.html` with your WhatsApp number.
- Update Instagram if needed.
- Replace the placeholder pricing/contact details with your preferred offer.
